# 班级、学生导入与课程 KC 管理完善记录

- 日期：2026-08-19
- 范围：课程班级管理、学生选课入口、课程 KC 总库、题库章节 KC、单题 KC 映射
- 数据库迁移：无

## 班级与学生

- 班级列表支持按班级名称或学年搜索，活动课程可修改班级名称并记录审计事件。
- 班级详情统一通过“导入学生”进入手动添加、Excel 批量导入和跨课程班级复制三种流程。
- 手动添加复用同学号、同姓名的全局账号；新账号继续使用 `S + 学号` 初始密码规则。
- 跨课程复制支持读取教师可管理的归档课程历史班级；目标课程已有选课的学生明确跳过，不修改账号身份和密码。
- Excel 模板、上传、预览、确认 URL 与既有事务语义保持不变。

## KC 管理

- 课程题库页底部新增课程 KC 总库，显示关联题库、题目总数和题库分布，并支持新增、重命名与安全删除。
- 题库详情改为当前题库的章节 KC 派生视图，区分主 KC、次 KC 关联数并提供题目入口。
- 单题编辑支持从所属课程中选择一个主 KC 和多个次 KC；跨课程、主次重复和重复次 KC 均由服务端拒绝。
- 主 KC 在课程题目编辑中为必填；失败提交不会修改题目、选项或既有 KC 映射。
- 原生 JavaScript 提供名称包含联想、键盘导航、ARIA 状态和次 KC 标签；无 JavaScript 时保留原生选择控件。
- 超长 KC、班级名称和页首文本允许安全断行；所有课程 KC 表单控件使用唯一 HTML 标识。
- KC 对应表导入、共享题库复制及已发布实验快照语义保持不变。

## 权限与审计

- 所有新增写接口使用 POST、CSRF、课程对象级访问控制和活动课程校验。
- 审计日志记录班级改名、手动选课、整班复制及 KC 创建、改名、删除的对象与计数，不记录学生密码。
- 课程归档后新增资源和修改操作只读；归档课程仍可作为历史名单复制来源。
