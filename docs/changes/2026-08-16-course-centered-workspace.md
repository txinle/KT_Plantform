# 教师课程中心式工作区重构记录

- 日期：2026-08-16
- 范围：课程模型、教师工作区、学生课程入口、历史数据迁移、权限与导出
- 数据库迁移：`accounts.0002-0004`、`question_bank.0002`、`experiments.0002`

## 课程强作用域

- 新增 `Course`、`CourseTeacher` 与 `CourseEnrollment`，平台角色仍只有管理员、教师和学生。
- 课程名称、课程代码和学期为必填字段；同一负责人下“课程代码 + 学期”唯一。
- 班级、题库、KC 和实验均纳入课程访问边界；实验只能组合同课程题库与有效选课学生。
- 同一学生账号可加入多门课程，但在同一课程只保留一条选课记录和一个班级归属。
- 共享题库跨课程使用事务性深复制，题目、选项和 KC 映射复制后独立维护。

## 历史数据迁移

- 为现有教师或管理员资源负责人创建“历史数据（迁移）”课程，并回填旧班级、题库和实验。
- 按旧班级建立选课关系；只有实验分配、没有可匹配班级的学生进入课程“未分班”。
- 按题目实际引用克隆课程级 KC；标准化同名 KC 冲突时合并题目链接并保留主 KC 标记。
- 保留原资源主键、实验版本、题目快照、会话、作答、事件及时间字段，并为历史实验版本写入课程名称、代码和学期快照。

## 教师与学生工作区

- 教师登录后进入“我的课程”，课程内导航为概览、题库、班级、实验、数据和设置。
- KC 仅在题库内部管理；学生仅在课程班级内部导入、转班和重置密码，不再提供并列全局入口。
- 课程学生导入支持复用既有全局学生账号，姓名、角色或重复选课冲突会使整批事务回滚。
- 学生登录后先选择已选课程，再查看该课程分配的实验；未选课程和跨课程对象不可访问。
- 课程归档后资源只读，已有会话也不能继续写入访问、草稿、提交、跳题或完成事件。

## 发布快照、导出与审计

- 实验发布版本新增课程名称、课程代码和学期快照，课程后续改名不改变历史导出语义。
- 实名可选字段导出新增三个课程快照字段；既有匿名 KT 与匿名导航 CSV 列结构保持不变。
- 新增课程创建、协作者变更、题库复制、学生批量选课、转班、课程归档和全局密码重置审计记录。
- 旧题库和实验地址对已迁移对象跳转或转发至课程路径；旧内部 `owner` / `class_group` 字段暂作迁移兼容，不再作为新工作区授权依据。

## 与主线界面和功能对齐

- 课程工作区复用主线既有的信息层级与响应式组件，不再使用压缩版平行模板。
- 课程概览恢复资源指标、主要工作、近期实验和最近题库；题库恢复可见性修改、更新时间、完整题型、难度和状态信息。
- 实验恢复排序与更新时间、生命周期、完整配置、发布快照、发布前检查、确认弹窗、已发布学生名单及结果页提交题数。
- 班级详情恢复学号/姓名筛选；学生导入恢复分步预览和课程班级限定的 Excel 模板下载。
- 当前课程身份与导航链接分离，长课程名使用截断而非缩小全局字体；当前页面有明确选中状态。
- 1440×900、390×844 及 768–1024 中间断点下，页面根节点无横向溢出；宽表仅在自身容器内滚动。
