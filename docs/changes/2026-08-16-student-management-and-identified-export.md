# 学生管理与实名数据导出完善记录

- 日期：2026-08-16
- 范围：教师端学生管理、实验结果筛选与数据导出
- 数据库迁移：无

## 学生管理

- 学生列表新增按学号或姓名搜索，以及按当前教师可管理班级筛选；搜索与班级条件可组合使用。
- 新增 `.xlsx` 学生批量导入模板。模板使用“学号、姓名、班级”中文表头，并附填写说明、示例和教师可用班级列表。
- 新增上传、校验预览、确认导入流程。导入采用整批事务，重复学号、未知班级、缺失或非法字段会阻止整批写入。
- 学号按文本处理，保留前导零；新学生初始密码为 `S` 加原始学号。
- 审计日志仅记录批量导入数量和结果，不记录密码。

## 实验结果与导出

- 实验结果页新增会话状态筛选，支持进行中、已完成、已超时和已作废，并限定为当前展示的最新实验版本。
- 新增实名可选字段 Excel 导出。导出粒度固定为“一名学生 × 一道题”，工作表名为“KT数据”。
- 新增包含原始学号、姓名和班级的实名导航事件导出，保持“一次访问一行”。
- 实名导出字段使用服务端白名单和固定列序；文本单元格保留前导零并避免被 Excel 解释为公式。
- 实名导出采用 POST、CSRF 和实验对象级权限，并记录导出类型、字段列表和行数，不记录具体数据内容。
- 原有匿名 KT、匿名导航和身份对照 CSV 路由及字段语义保持不变，移动至页面“兼容导出”区域。

## 文档与隐私提示

- 数据字典补充实名主分析表的字段、行粒度和导出语义。
- 页面与设计说明明确：实名文件仅限授权场景使用，不应作为匿名研究文件对外共享。
- 中文下载名同时提供 ASCII 回退名与 RFC 5987 `filename*`。

## 验证范围

- Django 系统检查、迁移检查、完整测试套件、静态资源收集、两项 JavaScript 语法检查和 `git diff --check`。
- 教师端学生筛选、批量导入预览、字段选择和状态筛选在 1440×900 与 390×844 视口下人工检查。
- 移动端表格使用局部横向滚动，页面根节点未出现横向溢出。
