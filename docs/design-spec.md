# 本地首版业务规则

## 范围

平台支持多个教师、班级、学生、题库和实验。学生可参加多个实验；姓名、班级和学号供内部管理与获授权的实名研究导出使用。实名导出不得在授权范围之外共享。

## 题目与 KC

首版支持单选、多选、数值和简答题，选择题最多 A–F。题目通过最小 CSV/XLSX 模板导入；难度、容差、解析等在后台补充。KC 对应表按题目序号映射主 KC 和次 KC，缺失名称自动创建。管理员导入的新 KC 为公共 KC，教师导入的新 KC 为私有 KC。

## 实验

实验支持固定、随机、按主 KC 与 0–1 难度参数分层随机三种排序。反馈支持无反馈、仅正误、正误与解析。时间支持无时限、总时限和单题时限。发布时复制题目、选项、答案、KC 和配置快照；发布后不可修改。

## 学生交互

学生在未提交题目间自由导航。每道题保存第一次进入时间、最后一次进入时间、访问次数、分配顺序、首次打开顺序和正式提交顺序。草稿自动保存但不判分；每题确认提交后锁定。

`last_visit_to_submission_ms = submitted_at - last_opened_at`，其含义是“最后一次进入该题至正式提交”的时长，不是完整作答时长。

## 状态与标签

未作答、跳过和超时不自动标记错误，`is_correct` 保持空值。只有正式提交题目才产生正确性与分数。正式提交时间以数据库事务完成时间为准。

## 数据导出

- 实名可选字段 Excel：默认主入口，每名学生每道题一行。教师可选择身份、会话、题目、行为、时间与作答结果字段；学号、姓名和班级直接使用原始值。
- 实名导航事件表：每次进入题目一行，包含原始学号、姓名、班级和会话内事件顺序。
- 匿名 KT、匿名导航和身份对照 CSV：保留既有字段与端点，只作为旧分析流程的兼容导出。
- 所有实名导出都要求实验所有者或超级管理员权限，使用 POST 与 CSRF，并记录字段范围和行数审计日志。
