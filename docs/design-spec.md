# 本地首版业务规则

## 范围

平台支持多个教师、班级、学生、题库和实验。学生可参加多个实验；姓名、班级和学号供内部管理与获授权的实名研究导出使用。实名导出不得在授权范围之外共享。

## 题目与 KC

首版支持单选、多选、数值、简答、填空和判断六类题目，选择题最多 A–F。题目通过最小 CSV/XLSX 模板导入；难度、容差、解析等在后台补充。数值题必须为有限数值，判断题使用“正确/错误”布尔答案，填空和简答可有其他可接受答案。课程 KC 是课程内唯一的知识点字典；题库“章节 KC”只是当前题库所引用课程 KC 的派生视图，不创建题库级副本。KC 对应表按题目序号映射主 KC 和次 KC，缺失名称自动创建；单题编辑只能从所属课程 KC 中选择一个主 KC 和多个不重复的次 KC。课程 KC 可新增、重命名，且只有未被题目引用时可以删除。后续 KC 改名不得改写已发布实验快照。

课程题目在首次保存、导入或复制进课程时获得 `CourseQuestionIdentity`。其 `course_sequence` 与 `stable_code` 是课程级永久编号，序号严格递增且永不复用；同课程内更换题库不改变身份，跨课程移动会被拒绝。题库内序号和题目代码仍可用于本地显示，但不能替代课程永久编号做跨题库连接。

## 班级与选课

学生账号属于平台全局，一个学生在同一课程只允许存在一条 `CourseEnrollment` 和一个课程班级归属。课程班级支持按名称或学年搜索，并可在活动课程内修改班级名称；班级改名不得改写既有实验参与者的班级快照。学生可以手动加入、通过 Excel 批量导入，或从教师有权管理的其他课程班级复制。三种入口都复用同学号、同姓名的既有学生账号；新账号初始密码为 `S + 学号`。跨课程复制只新增目标课程选课，已加入目标课程的学生跳过，不自动转班，也不修改姓名或密码。

## 实验

实验支持固定、随机、按主 KC 与 0–1 难度参数分层随机三种排序。反馈支持无反馈、仅正误、正误与解析。时间支持无时限、总时限和单题时限。发布时复制题目、选项、答案、KC 和配置快照；发布后不可修改。

实验还支持全量题池与按题型配额抽题两种选题方式。配额对六种题型独立设置非负数量，总配额至少为 1；发布时重新校验题库全部可用题的库存，并冻结完整候选池、配额、库存、抽样盐和算法版本。学生首次开始会话时才在发布候选池内无放回抽取个人题集；这不是发布时为每名学生预先写入题单。

草稿实验的参与者由“参与班级 + 显式纳入 − 从已选班级排除”构成。规则只接受同课程、可用班级中的在读学生；同一学生不能同时纳入和排除。保存规则更新当前名单预览；发布时重新从最新有效选课关系计算名单，且至少需要一名参与者，随后冻结 `ExperimentStudent.class_snapshot_name`、题目、配置和参与名单。

涉及课程参与规则、发布和课程名单写入的事务遵循锁序：实验 → 课程 → 班级（按主键）→ 有效选课/参与者记录。锁定后必须再次验证草稿状态、课程、班级和选课条件；条件已变更时拒绝写入，避免班级停用、转班或发布并发形成错误名单快照。

## 学生交互

学生在未提交题目间自由导航。每道题保存第一次进入时间、最后一次进入时间、访问次数、分配顺序、首次打开顺序和正式提交顺序。草稿自动保存但不判分；每题确认提交后锁定。

同一学生和同一发布版本只有一个会话。会话保存独立的 `sampling_seed`、`ordering_seed` 与 `sampling_algorithm_version`：抽题种子只决定配额抽样，排序种子只决定随机或分层排序。重复进入仅读取已保存的 `StudentQuestionAssignment`，不得重新抽题或重排。学生题号导航、会话详情和报告始终按个人的 `assigned_sequence_index` 展示；课程永久编号只用于追溯。

`last_visit_to_submission_ms = submitted_at - last_opened_at`，其含义是“最后一次进入该题至正式提交”的时长，不是完整作答时长。

## 状态与标签

未作答、跳过和超时不自动标记错误，`is_correct` 保持空值。只有正式提交题目才产生正确性与分数。正式提交时间以数据库事务完成时间为准。

## 数据导出

- 实名可选字段 Excel：默认主入口，每名学生每道题一行。教师可选择身份、会话、题目、行为、时间与作答结果字段；学号、姓名和班级直接使用原始值。
- 实名导航事件表：每次进入题目一行，包含原始学号、姓名、班级和会话内事件顺序。
- 匿名 KT、匿名导航和身份对照 CSV：保留既有字段与端点，只作为旧分析流程的兼容导出。
- 所有实名导出都要求实验所有者或超级管理员权限，使用 POST 与 CSRF，并记录字段范围和行数审计日志。

实名 Excel 在同一学生内按课程永久编号排序，再以个人分配顺序作为次序；匿名 CSV 的 URL 与 headers 保持不变。按题型配额抽题时学生可能收到不同题目集合，因此系统不提供跨学生裸分可比性的保证；任何能力或组间比较都必须另行处理题目组成与测量模型。

## 编辑、参与者与会话详情路由

| 操作 | 方法与路径 | 边界 |
|---|---|---|
| 编辑班级 | GET /teacher/courses/{course_pk}/classes/{class_pk}/edit/ | 课程可写且调用者有课程访问权。 |
| 保存班级名称、学年和启停状态 | POST /teacher/courses/{course_pk}/classes/{class_pk}/update/ | CSRF 与 state_token；拒绝静默覆盖并发更新。 |
| 编辑题库元数据 | GET /teacher/courses/{course_pk}/banks/{bank_pk}/edit/ | 仅课程负责人、题库所有者、管理员或超级管理员。 |
| 保存题库名称、说明和可见性 | POST /teacher/courses/{course_pk}/banks/{bank_pk}/update/ | CSRF；锁定可写课程与题库，不修改题目、选项或 KC 映射。 |
| 保存草稿参与规则 | POST /teacher/courses/{course_pk}/experiments/{experiment_pk}/assign/ | CSRF；发布后不再接受规则修改。 |
| 查看单会话作答详情 | GET /teacher/courses/{course_pk}/experiments/{experiment_pk}/sessions/{session_pk}/ | 课程负责人、管理员或超级管理员，仅可访问所属实验的会话。 |
| 下载单会话 Word 报告 | POST /teacher/courses/{course_pk}/experiments/{experiment_pk}/sessions/{session_pk}/word/ | CSRF；报告只包含作答核对字段。 |

Word 报告只展示身份与发布快照、实际题数、题目内容、学生答案、标准答案和作答状态；禁止包含 KC、难度、用时、访问/导航或解析。
