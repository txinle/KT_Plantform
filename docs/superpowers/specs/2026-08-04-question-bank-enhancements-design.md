# 题库功能完善设计

## 目标

完善教师题库工作流中的导航、可见性管理、题目标识展示和导入模板获取，同时保持现有题目编码、导入解析、实验快照和权限语义不变。

## 范围

本次变更包括：

- “我的题库”表格中的题库名称与题目数量可进入题库详情。
- 题库可见性可在列表内切换为“私有”“共享”或“归档”，选择后立即保存。
- 题库详情中的题目标识显示为 `Q1`、`Q2` 等简洁形式。
- 题目导入页提供题目 CSV 示例下载。
- KC 导入页提供 KC 对应表 CSV 示例下载。

本次不修改数据库结构、题目持久化编码、CSV 列定义、导入解析规则、已发布实验快照或学生答题流程。

## 交互设计

### 题库列表导航

题库名称和题目数量都使用指向现有题库详情路由的普通链接。保留“管理”按钮，确保原有显式操作入口继续可用。链接具备可见焦点样式，并沿用现有表格密度和数字排版。

### 可见性切换

每行当前状态使用原生 `<details>` / `<summary>` 作为可交互控件。点击状态文字后展开包含“私有”“共享”“归档”的下拉选择，并把选择框作为后续键盘焦点；选中不同值时立即提交。该结构无需 JavaScript 也能展开。

提交使用独立、受 CSRF 保护的 POST 路由。后端只从当前用户拥有的题库集合中取对象；超级管理员延续现有 `_owned_bank` 规则。合法提交保存可见性并返回题库列表，同时显示成功消息。非法值不写入数据库，并显示错误消息。表单提供无 JavaScript 提交按钮作为降级路径。

页面使用原生 JavaScript 监听带专用 `data-*` 标记的选择框 `change` 事件并提交所属表单；不引入新依赖或 Fetch 合约。

### 题目标识

题库详情只在题目清单中将辅助标识渲染为 `Q{{ q.sequence }}`。数据库中的 `Question.code` 及其默认生成规则保持不变，以避免破坏管理页、日志或未来数据引用。

### CSV 示例下载

题目导入页和 KC 导入页分别显示明确的“下载 CSV 示例”链接。下载使用两个受教师或管理员角色保护的 GET 路由，并返回仓库中现有的：

- `fixtures/question_import_template.csv`
- `fixtures/kc_mapping_template.csv`

响应采用 UTF-8 CSV 内容类型、附件下载头和稳定文件名。下载端点不接受用户路径参数，避免任意文件读取。示例文件继续作为导入格式的单一事实来源，不复制一份模板内容到视图或模板中。

## 数据与权限边界

- 可见性修改仅影响所选题库的 `visibility` 与模型自动维护的 `updated_at`。
- 共享题库复制规则和共享题库查询规则保持不变。
- 归档题库在实验配置中的现有过滤规则保持不变。
- 下载示例不读取题库数据，但路由仍限制为教师和管理员角色。
- 不改变访问记录、草稿、正式提交、计时、快照、匿名导出、CSRF 或幂等语义。

## 错误处理与可访问性

- 可见性非法值返回列表页并显示内联消息，不静默失败。
- 非所有者访问可见性更新端点沿用现有 404 隐藏对象策略。
- 示例文件缺失属于部署错误，端点返回 404，不暴露服务器路径。
- 链接和选择框使用原生键盘语义；状态文字始终可见，不依赖颜色表达。
- 自动提交行为保留无 JavaScript 保存按钮，并避免原生 `alert()` 或 `confirm()`。

## 测试与验收

自动化覆盖：

- 题库所有者能够更新可见性，且成功后重定向并持久化。
- 非所有者不能更新题库可见性。
- 非法可见性值不写入数据库。
- 两个 CSV 下载端点返回正确文件名、内容类型和现有模板内容。
- 题库列表包含题库名称、题目数量的详情链接以及自动提交控件。
- 题库详情显示 `Q1`，不再显示 `Q0001`，且数据库编码仍保持 `Q0001`。

完成后运行仓库要求的 Django 检查、完整测试、静态文件收集和两个 JavaScript 语法检查；并在 1440 × 900 与 390 × 844 下检查受影响的教师页面。学生流程未被修改，但仍执行现有学生相关回归测试。
