# 管理与协作 Site 本地迁移

**Goal:** 将已认可的管理与协作 Site 的页面及能力接入本地真实 Django/Vue 平台。
**Architecture:** Django 继续裁决权限、生命周期、快照和导出；Vue 复制 Site 的结构与视觉，展示服务端数据。保留 `/admin/` 技术后台和已有教师业务 URL，新增 `/manage/` 业务工作台。
**Tech Stack:** Django 5.2 / PostgreSQL 17 / Vue 3 / TypeScript / Vite 8。

参考源：`E:/ATOP/sites/kt-admin-collaboration-demo/dist/`，已发布版本 8dab80c。用户已认可设计并明确授权补齐本地缺失功能；后续明确授权提交推送 GitHub 并运行 CI，暂不部署服务器。

## 功能对应

| Site 模块 | 本地实现与约束 |
| --- | --- |
| 管理概览 | 全平台真实账号、课程、班级任务、导出、操作记录统计及入口 |
| 账号管理 | 教师用户名、学生学号分开显示与校验；新增、编辑、停启用、重置密码；自身及最后管理员保护 |
| 课程与班级 | 课程/班级列表和详情、创建编辑、负责人移交、归档恢复、删除影响预览及符合服务约束的执行；真实学生名册、导入与调班 |
| 教学资源 | 全平台题库、题目、课程知识点；复用既有题库/题组/导入/复制/知识点变更流程，不能回写冻结快照 |
| 实验与数据 | 真实实验、班级任务、排期/结束操作、导出记录、单实验及全部实验逐包范围预览与正式八文件导出、现有清除流程 |
| 操作记录 | 服务端只读审计及变更详情，不能记录密码 |
| 课程设置 | 课程基本信息、负责人、协作成员搜索/添加/编辑/移除；题库、班级、实验、数据查看、数据导出五项独立服务端授权；负责人移交、归档 |

## 验收边界

不复制 Site 虚拟数据，不将模拟导出称为真实研究包，不用前端按钮隐藏代替权限，不绕过已有删除和冻结保护。差异必须是本地真实数据、权限或业务状态造成；结构、色彩、字号和组件间距按 Site 核对。检查实际差异并记录已完成的验证，不重复运行无变化的全量测试。
