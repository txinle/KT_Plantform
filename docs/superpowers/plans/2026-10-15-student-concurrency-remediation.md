## 3. 实施方案与接口约束

### A. 首题与后台采集

- 初始化等待本地事件、检查点、恢复材料可靠落盘；IndexedDB 失败仍阻止正式作答。
- 使用现有本地 `recordCheckpoint()`，不等待普通 resume 检查点上传确认。
- 初始化暂缓自动上传；首题具备可操作条件后启动上传并小幅随机错峰。保存、切题、提交、离页的强制确认仍可立即触发。
- 时钟同步不是首题开放前置条件；保留同步前原始时间、质量标记，不改写精度。
- 启用输入前确认租约有效，失效时续租；必要授权请求仍在关键路径。
- 拆出 Service Worker 注册、公共页面壳和静态资源准备，进入任务列表可执行一次；真正冷启动仍计完整点击时间。
- 激活前不得取得明文题目、答案或评分资料；激活后准备本会话授权内容。

### B. 工具请求与任务列表

- 预生成和恢复投影复用服务器现有工具配置判断；无疑点、检查、提示、规则时不返回 `research_tools_url`。
- 规则判断、曝光记录不变；必要刷新最多一个在途，隐藏/离线暂停，恢复重新核验。
- 根据冻结配置而非当前 due rules 决定是否需要检查，避免关闭未来规则。
- DB 聚合 Attempt 总数和原口径完成数，不加载答案、轨迹、完整 Attempt。
- 未开始任务保持预览题数优先、版本题数兜底，用计数代替加载快照。
- 列表缓存不决定开始权限；开始仍由服务器核验。

### C. PostgreSQL 登录活跃续期

增加兼容现有 Django 数据库会话格式的 SessionStore，复用 `django_session`，不新增业务表或批量转换。

- 登录、退出、密钥轮换、内容修改立即保存。
- 读取时保留同次已读取的 `expire_date`，无需额外查询来判断续期。
- 目标过期时间 = 向上取整到下一个 30 秒边界的活跃时间 + 1800 秒。
- 当前过期时间已覆盖目标则不写库；仅条件更新仍存在、有效且过期更早的记录。
- 并发不能缩短过期时间、复活退出或删除的会话；同一窗口纯续期一次有效行更新。
- Cookie 不早于服务器有效期，服务器为最终过期权威；教师、管理员、自定义策略不变。
- 应用 429 可发生窗口唯一必要续期，但不每次完整保存；Nginx 拒绝不进入 Django/DB。
- 真实 SQL 写入次数验收，不能只看 modified。

参考：https://docs.djangoproject.com/en/5.2/topics/http/sessions/

### D. 事务准入与入口保护

prepared 使用 PostgreSQL 事务级非阻塞名额，历史协议不变。

- 固定 advisory lock 命名空间，名额 `0…C−1`；同一个外层激活事务内调用 `pg_try_advisory_xact_lock`。
- 从学生标识位置轮转，最多 C 次；无名额立即结束事务，429 `START_BUSY`，不预约、不计时。
- 获名额后锁学生会话，核验参与资格、课程访问、任务状态、期限，一次写开始事实、首题、租约、固定回执。
- 已有回执优先恢复；同会话实际执行中返回 202 executing，不重复开始。
- 提交、回滚、事务结束释放；事务仍在运行继续占额，不按客户端超时擅自释放。
- DB 不可用明确失败，不无限制降级。保留回执字段和执行标识。
- 新流程不调用 Redis 名额申请/释放/取消栅栏协调；服务器开关切换，仅旧执行排空后切换。保留旧记录、恢复代码和历史表。
- 必须事务级锁，禁止 session 级锁。参考：https://www.postgresql.org/docs/17/explicit-locking.html
- Nginx 只对开始请求执行共享速率限制：首轮 R=64/s、突发 8，超出返回一致 JSON `START_BUSY`、`Retry-After`；不按校园出口 IP 共用低额度。
- 客户端同一启动身份、最多一个在途，遵守 Retry-After，随机退避逐次扩大至最多 4 秒。
- 保留 60 秒观察预算；所有失败、超时计入，不放宽 5/10 秒验收。

### E. 登录、SQL 与监测

- 分别计时认证池等待、密码校验、会话建立、响应、离线缓存清理、导航、课程加载。
- 不降哈希强度、不缓存密码、不用廉价哈希压测账号；复用登录返回的身份和 CSRF，不增加状态确认。
- 启动使用首题预生成投影，不遍历整卷、不重新生成题干。定点合并重复读取，权威事务内保留权限和期限核验。
- 分别记录保存、采集、切题的请求、SQL、提交、连接等待、锁等待；嵌套计时不重复相加。
- 压测轻量计时，完整 SQL 追踪仅小规模诊断。

接口：保留 URL 和启动 200/201/202/429 合同；无工具省略已有可选入口；增加服务器准入模式配置。无新公开业务 API，不改答案、信心、事件 schema。
