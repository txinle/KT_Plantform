## 不可改变的边界

- 首次登录只提醒，可选择立即修改或暂不修改；不阻断课程、实验或作业。
- 初始密码状态使用显式字段。新建账号、教师重置时开启，成功修改密码时关闭。修改学号不修改密码，也不重新推断密码状态。历史账号仅做一次性安全识别，后续以显式状态为准。
- 提交流程：作答/修改 → 点击提交 → 信心评价或跳过 → 最终确认 → 答案与信心原子提交并锁定。保留实验关闭/全部/抽样设置，不重新抽样。
- 中断恢复原任务、会话、题目及草稿，计时继续。请求结果不明时核验权威状态，不重复有效提交。
- 教师只能查看已正式提交成功的答案与过程；未提交内容在后台保留但不进入教师详情接口。
- P3 三级：学生主表每学生一行；学生详情每次有效正式作答对应的题目一行；点击题目才展开过程。内部聚合键包含学生、实验/参与、题目、有效正式作答，不按题号跨任务/session合并。
- 教师正式可视字段使用业务白名单。session/attempt/snapshot/event/submission ID、数据库主键、内部版本、哈希、Schema、表名、路径、技术关联键均不显示，也不得转移到 Tooltip、折叠区、错误详情。学号、业务题号、课程编号可以显示。必要查询键仍可供内部路由和关联使用。
- P4 核心：进入题目 → 答案状态变化 → 正式提交。信心结果放在题目摘要。最终提交反向重建有效状态链的证据真实性优先于时间线完整性；不能按邻近时间戳拼接归属。无法证明关联时标记证据缺口。
- 展示层仅做语义聚合，不使用“相邻 1 秒”阈值，不覆盖或删除原始事件。清空、重填、返回原答案等真实变化必须保留。
- 不扩展导出格式。导出可读性留后续任务；本轮仅对既有原始导出做证据完整性回归。
- 不新增旧测试数据兼容层，不修改其他页面全局样式。

## 实施任务

### A. 账号提醒

显式初始密码状态与提醒展示时间分别维护。弹窗实际渲染后才幂等确认展示。永久修改密码入口，校验当前密码、新密码及确认密码。失败不改变状态。教师重置重开提醒。历史识别命令默认预演，显式应用且不重置密码。停用强制改密拦截及路由跳转；同步登录/session/密码修改接口与 Vue/独立页。

### B. 提交与恢复

先修复信心分配把 response_status 与配置比较的问题。第一次点击提交不评分、不锁定。评价绑定答案版本，返回修改后旧评价失效。未操作量表不当有效值；明确跳过最终保存 skipped；未分配评价不伪装跳过。最终请求以稳定令牌、目标答案状态和信心结果完成单事务提交。保留权限、租约、CSRF、截止时间和反馈规则。

恢复端点只读核验任务、会话、题目和提交结果。区分网络不可达、登录失效、截止、关闭、冲突、服务器异常。无权威结果不得声称刷新成功。响应丢失后重用令牌，恢复持久化草稿，不新开会话、不延时。

### C. 教师预览与过程

服务端授权范围内搜索学号/姓名，每页20学生。主表展示学生身份、班级、实验数、进度、状态、操作。学生详情按实验/参与范围展示有效正式作答行；题目摘要包含业务题号、最终答案、正确性/得分、时长、选择题可比修改次数、信心、提交状态/时间。完整题目、答案和过程按需展开。移动端全屏详情，关闭恢复列表状态。

统一后台过程投影供 P3 与 P4 使用。核实 Attempt.final_response_event、SubmissionEvent 和 response_committed 的关联，沿父事件关系验证有效链，拒绝跨 attempt/session/题目混入。排除提交后、未采纳分支和仅草稿的内容。验证哈希、父子状态与正式提交最终答案。缺口保留且不猜测。文本摘要可展开完整前后版本；采集状态与展示分组分离。

### D. 测试实验清理

仅 KT01 / EDA技术 中精确名为 test 的实验。调查时课程1、实验1、2 sessions、30 attempts；执行前重新确认，不盲用旧ID。新增限定实验的默认预演/显式执行命令，不能调用课程清理扩大范围，不能放宽普通正式实验删除约束。清理目标独占的任务、版本/参与快照、会话、作答、提交、评分、信心、原始事件、检查点和派生数据。相关导出按依赖失效。保留课程、班级、账号、成员关系、KC、题库和其他实验/共享资源。事务、审计、失败回滚、提交后文件处理；不做旧流程迁移。
